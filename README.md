
# IA de Apostas Profissional

## Recursos
- Interface visual em Streamlit
- Modelo avançado de ML
- xG
- Forma recente
- Odds
- Probabilidades automáticas
- Value Bets (EV)

## Instalação

```bash
pip install -r requirements.txt
```

## Executar

```bash
streamlit run app.py
```
